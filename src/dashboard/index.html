      How to use IsleMap

      A full tour highlights every module, tab, and major setting on the real UI.

      What you’ll learn

      Every menu and settings group is covered

      • Setup — choose Asset Location and/or Primal Pinas !map (required before Show map)
      • Modules — Setup, Overlay, Destination, Group, Game & hotkeys, Screenshots, Recording, Tutorial, Contributors, Updates
      • Overlay tabs — Style, Border, Effects, Sweep, Frame, HUD, Places, Opacity, Layout, Preview
      • Effects — Audio beat is the default rim FX; tune beat knobs, random gradient, and legend tint
      • Destination — Map pin & Waypoint identity / navigation
      • Group — username + PC ID, create/join a squad, share live pins
      • Game tabs — Hotkeys, Setup, Filters, Data (+ Dev when unpackaged)
      • Screenshots — map or full-screen captures, notifications, clipboard, hotkeys
      • Recording — desktop audio, background encode, clip library under Videos\IsleMap

      • Contributors — people who help build IsleMap
      • Updates — check GitHub releases and install newer versions

      Tip: press Esc or Skip anytime. Use Back / Next between highlights.

      Effects — Audio beat (default)

      Rim FX that reacts to desktop / game sound

      1. Open Overlay → Effects. Effect defaults to Audio beat.
      2. Choose Beat style — Circle spectrum (av-circle) or Pulse rings. For circle bars, tune Size (0–100), Thickness, Spacing, Rim offset, and Rotation.
      3. Optional: enable Random gradient color for shifting rim colors.
      4. Tune Sensitivity, Punch, Smoothness, Bass weight, Motion, and Detail/Rings.
      5. Turn on Random gradient on radar legends to tint place icons with the beat colors.
      6. Compass N/S/E/W letters also pick up rim FX tints while an effect is active.

      Screenshots

      Radar or full-monitor captures

      1. Open Screenshots in the sidebar.
      2. Library — filter All / Map / Screen, capture, open folder, or refresh.
      3. Settings — notifications, clipboard copy, and rebind map / screen hotkeys.
      4. Files save under Pictures\Screenshots\IsleMap.

      Recording

      Screen capture with desktop audio and clip library

      1. Open Recording → Controls. Start / Stop and Pause with the transport or hotkeys.
      2. Toggle Desktop audio for system / game sound via Windows loopback.
      3. Encoding can finish in the background — you can start another take while a clip is pending.
      4. Media — preview finished MP4s, manage the library under Videos\IsleMap.

      Group — share pins with friends

      No accounts. Username + PC ID only.

      1. Open the Group module in the sidebar.
      2. Enter a username (your PC ID is created automatically).
      3. Create group and share the code, or type a friend’s code and Join.
      4. In-game, click Asset Location so your pin updates for the squad.
      5. Squadmates show as colored dots on the radar. Hosts can Remove members.

      Your username and PC ID are saved on this computer and survive app updates.
